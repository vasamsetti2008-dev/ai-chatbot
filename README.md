AI Chatbot with Ollama

A simple AI chatbot built using Python, Flask, and Ollama.

Features

- Chat with a local AI model
- Simple web-based interface
- Runs locally on your computer

Technologies Used

- Python
- Flask
- Ollama
- HTML, CSS, JavaScript

Requirements

- Python
- Ollama
- Git

How to Run

1. Install Ollama and download a model:
   
   ollama pull llama3.2:1b

2. Start Ollama.

3. Install the required Python packages:
   
   py -m pip install flask ollama

4. Run the chatbot:
   
   py app.py

5. Open your browser and visit:
   
   "http://127.0.0.1:5000"
